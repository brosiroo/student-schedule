# جدولي الدراسي

موقع HTML/CSS/JS مستقل لإدارة الجدول الدراسي.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## المميزات
- إضافة/تعديل/حذف المواد
- اختيار عدة أيام
- ألوان للمواد
- كشف تعارضات المواعيد
- حفظ تلقائي عبر localStorage
- Dark/Light mode
- تصدير واستيراد JSON
- طباعة
- تصدير PNG وPDF
- RTL + Responsive

ملاحظة: تصدير PNG/PDF يستخدم مكتبات CDN، لذلك يحتاج اتصالاً بالإنترنت وقت التصدير. بقية الموقع يعمل محلياً.
